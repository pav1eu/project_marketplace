# Домашняя работа

### Описание:
В домашней работе представлен простой функционал классов Product и Category, который имеет методы подсчёта продуктов
и категорий продуктов, метод добавления новых продуктов.
Добавлены методы __str__ и __add__ для классов.
Усовершенствованы методы add_product и __add__. Теперь складывать можно только продукты одного класса (__add__).
Проверка для add_product производится с помощью функции issubclass().
Добавлены 2 дочерних класса Smartphone и LawnGrass
Весь функционал покрыт тестами и прикреплен htnl файл с отчетом о покрытии.
```
poetry run pytest test --cov
```
Функционал проекта можно проверить из файла main.py
```
python main.py
```
